# A small mold simulation.

## bloxd.io lobby name: [moldsim_beta](https://bloxd.io/play/classic/moldsim_beta)

### A mold simulator, where you can grow your molds, fight with others or clear this world from molds, if you are a mad guy.


# How to add your molds?
### Easy way:
Just add new mold object with paramatres to the moldsConfig array. 

### Hard way:
The same, but specify the randomTick function.
